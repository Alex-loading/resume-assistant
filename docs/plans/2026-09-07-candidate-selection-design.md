# v0.2.1 候选资料优先选择

网页填写页识别到单条或多条候选时，下拉框默认仅显示这些候选。单条沿用自动选中，多条需要用户选定经历。

下拉框旁提供「从所有字段中选择」按钮。展开后按「候选资料」「其他资料」分组且不重复；用户可选择任意资料，也可返回候选。返回时保留仍属于候选的选项，清除不属于候选的手动选择（单条候选重新选中），避免预览或填写使用隐藏的旧选项。

没有候选时直接列出全部资料，不显示切换按钮。网页输入框或简历版本切换时恢复候选优先；当前输入框值变化和填写过程保持用户的选择范围。快捷复制继续保持候选置顶。

通过真实原生侧栏验证单条及多条候选、展开全部并手动填入、返回候选的选择清理、切换输入框和简历版本、无匹配时的手动选择。

验证结果：24 项单元测试和 25 项真实浏览器检查全部通过，扩展安装包通过 ZIP 完整性检查。
