# v0.2 常驻侧栏与输入框定位

用户要求：填写时面板保持显示；默认快捷复制；点击网页输入框后，插件自动匹配字段并高亮。

采用 Chrome / Edge 原生侧栏，工具栏按钮打开全窗口侧栏。新增 sidePanel 权限，最低 Chrome 版本升至 116。移除旧 popup 入口，使用 panel.html / panel.mjs / panel.css；数据 schema 继续使用版本 1。

输入监听按当前标签临时注入 isolated world。focusin / click 获取输入框，input / change 更新当前字段内容；普通动态输入通过事件委托处理，同源 iframe 和开放 Shadow DOM 通过根节点发现处理。监听只发送字段描述，资料匹配在可信侧栏内进行。

每个字段使用稳定 token，绑定文档、URL 与语义签名。侧栏绑定当前窗口、标签和 documentId，使用连接代次与事件序号忽略过期结果。写入前再次确认当前标签和字段状态。关闭或换页通过连接租约清理监听，避免旧连接延迟关闭误伤新连接。

复制页默认显示，匹配项置顶高亮；多条经历高亮候选，不自动选定。网页填写页为同一个目标提供手动字段选择与预览。用户点击才填入；默认保留已有内容，切换字段重置覆盖开关，并保留撤销能力。

通过 24 项数据与匹配单元测试、21 项浏览器检查。原生侧栏测试在独立有界面 Chrome 中运行，以 CDP 附加真实 SIDE_PANEL 上下文，覆盖默认复制、常驻显示、实时高亮、单项填写、多候选、覆盖/撤销、动态输入、同源 iframe、Shadow DOM、页面导航、标签切换和关闭后的监听释放。
