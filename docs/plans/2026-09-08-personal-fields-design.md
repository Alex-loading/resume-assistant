# v0.2.2 身份证号和个人介绍

在个人信息中新增可选文本字段 `basic.idNumber`，保存、导入导出、快捷复制和网页填写均保留完整字符串，包括首位零和末尾 X。按明确的身份证号名称及常见英文属性匹配，不把通用 id、护照号或无类型的证件号猜成身份证号。

现有 `extras.summary` 继续存储介绍内容，界面名称改为「个人介绍」，位于「常用长文本」。补充个人介绍和 personalIntroduction 匹配名称，继续兼容自我介绍、自我评价、个人简介等现有名称，避免生成重复字段或丢失旧资料。

数据格式保持版本 1。旧版数据缺失身份证号时补为空字符串，原有介绍原样保留。沿用候选优先、手动点击填写、已有内容保护与撤销机制。

验证覆盖旧备份兼容、文本和多行内容往返、字段匹配及第三方字段排除，以及真实侧栏中的保存、复制入口和候选填写。

34 项单元测试和 27 项真实浏览器检查全部通过；v0.2.2 安装包通过 ZIP 完整性检查。测试身份证号使用无效地区码的虚构数据。
