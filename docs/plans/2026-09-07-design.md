# 简历匣：首版设计与验收范围

用户希望用浏览器扩展管理简历，并快捷填写招聘网页。首版采用 Chrome / Edge Manifest V3、原生 JavaScript 模块和 CSS，无服务端，无运行时第三方依赖，无构建步骤。

## 范围

- 资料工作台：多个简历版本、个人信息、教育/工作/项目多条经历、常用长文本，自动保存，JSON 追加导入与备份导出。
- 招聘页弹窗：选择版本、搜索并复制字段；扫描页面后预览匹配，允许手动选择资料字段，勾选后填写，默认保留已有值，支持撤销。
- 识别：中英文 label、aria、placeholder、name、autocomplete；同源 iframe 和开放的 Shadow DOM。多条经历和不确定匹配需手动选择确认。
- 填写：原生 input、textarea、select，触发原生 setter 与 input/change 事件；不自动提交表单。自定义下拉、日期弹层、跨域 iframe、文件上传通过复制/手动完成。
- 本地个人资料导入文件来自已有修订简历，不包含在扩展分发包。

## 数据和权限

chrome.storage.local 保存版本 1 数据，限制 content script 访问整个资料库。仅申请 storage / activeTab / scripting。点击扩展后按需注入 isolated world 脚本，无全站 host_permissions、无后台自动扫描和远程数据传输。网页在实际填写后可读取所填写的内容；本地存储和 JSON 备份未加密。

## 实现顺序

1. 定义数据模型、导入验证和字段匹配规则。
2. 实现资料工作台、版本管理和个人资料导入。
3. 实现页面扫描、预览、填写、撤销及快捷复制。
4. 测试歧义、已有值、禁用/隐藏字段、表单事件、跨框架输入；验证扩展本体和工作台界面，打包并写安装说明。

## 首版边界

未指定具体招聘网站，通用识别不能承诺每个网站适配。暂不包括 PDF/DOCX 自动解析、云同步、AI 改写、自动新增网站经历行或自动投递。首版保留模块边界以增加站点适配器。

参考：[Chrome activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)、[scripting](https://developer.chrome.com/docs/extensions/reference/api/scripting)、[storage](https://developer.chrome.com/docs/extensions/reference/api/storage)。
